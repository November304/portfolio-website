# Shader Tests

This project groups together my **first experiments with shaders**, carried out on **ShaderToy**.  

## Project Details

### Context  

The objective was to discover the **GLSL** language and experiment with real-time visual rendering. These tests allowed me to understand shader logic and introduce myself to a new way of thinking about graphics programming.  

### What I Learned  
- Write code in **GLSL**,  
- Think in terms of **pixels and fragments**,  
- Understand the basics of **fractals, visual effects and procedural animations**,  
- Lay the foundation for future integrations in engines like **Unity**.  

### Next Steps  
I would like to apply this knowledge to more concrete projects:  
- Use shaders in **Unity** to enrich my games,  
- Experiment with other mathematical formulas to create more complex effects.
