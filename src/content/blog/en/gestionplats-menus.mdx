# Dish and Menu Management Project

This application was developed as part of my **BUT** degree to manage **dishes and menus** for a restaurant or food service, with complete CRUD functionality and advanced features for nutritional tracking.

## Project Details

### Context  

The project consisted of creating a complete application to manage dishes and menus, with filtering, pagination, and visualization of nutritional information.  

### Main Features  
- Complete management of **menus and dishes**: creation, modification, deletion.  
- Automatic calculation of **calories** for each menu.  
- **Filtering and pagination** to facilitate navigation.  
- **Notifications** to inform the user of changes.  
- **Dark/light theme** for the interface.  
- **Interactive charts** to visualize calorie distribution.  

### What I Learned  
- Development of a complete **Spring/Java** application.  
- Creation of an efficient CRUD with pagination and filtering management.  
- Integration of **notifications and interactive charts** to improve user experience.
