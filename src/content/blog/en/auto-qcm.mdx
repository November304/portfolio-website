# Auto QCM

**Auto QCM** is a collaborative web application developed as part of my **BUT** degree, enabling the creation and generation of personalized MCQs thanks to AI.

## Project Details

### Context  

This project was completed as a group within my Computer Science BUT program. The objective was to propose an innovative tool to facilitate teachers' work in creating questionnaires.  

### Delivered Features
- **MCQ Generation** from course materials through integration with a **generative AI**.  
- **Manual creation** of MCQs directly via the web interface.  
- **Integration** with educational platforms such as **Moodle** and **AMC** for seamless integration into already-used environments.  
- **Commercial pitch**, which allowed me to develop skills in **communication** and **video editing**.  


### What I Learned
- Using Django to create a web application.  
- Setting up integrations with external systems (**Moodle**, **AMC**).  
- Developing communication skills through the realization of a pitch.
