# Flappy Bird

**Flappy Bird** is a project completed as part of a multimedia course during my **BUT** degree. The goal was to create a 2D clone of the famous mobile game to discover the basics of the **Unity** engine.

## Project Details

### Context  

This project was part of guided learning on Unity. Although I was already familiar with the tool, it allowed me to strengthen my foundations and go further in experimentation.  

### Main Features
- Recreation of the classic **Flappy Bird** gameplay.  
- Addition of **animations** to improve smoothness.  
- Implementation of a **parallax effect** to enrich the visual rendering.  

### What I Learned  
- Deepening my knowledge of **Unity 2D**.  
- Managing **animations and visual effects** in a simple game.  
- Using **C# scripts** for game mechanics.
