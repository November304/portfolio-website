# Locur4iot Website

**locur4iot** is an internal website developed as part of my **BUT** degree, enabling real-time visualization of distance sensor data deployed indoors.  

## Project Details

### Context  

This project was completed as a team for the **IUT**, in collaboration with researchers from the **Locura4iot** group. The objective was to set up an internal website to visualize and exploit data collected by connected sensors.  

### Main Features
- Connexion au **courtier MQTT** du testbed de l’IUT.  
- Récupération et **stockage des données capteurs** en base de données.  
- **Visualisation des données** via une interface web claire et fonctionnelle.  
- **Mise à jour en temps réel** des informations affichées.  

### Défis rencontrés  
La gestion de la communication via **MQTT** et l’actualisation des données en temps réel ont représenté les plus grands défis techniques. Il a fallu penser l’architecture du site pour assurer à la fois la fiabilité et la performance de l’application.  

### Ce que j’ai appris  
- Mettre en place un site web en **PHP** connecté à une base de données.  
- Manipuler des flux de données temps réel via **MQTT**.  
- Travailler efficacement en équipe dans le cadre d’un projet académique.
