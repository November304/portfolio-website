# Countdown Crew

**Countdown Crew** is a cooperative multiplayer game where one player must defuse a bomb by communicating with another player who has the manual.  

## Project Details

### Concept  

Inspired by the game *Keep Talking and Nobody Explodes*, this project offers a similar experience but enriched:  
- Introduction of **random elements in the manual**,  
- Creation of **original new modules**,  
- System of **asymmetric cooperation** between two players (the defuser and the expert).  

### Developed Features  
- **Generation and display** of a bomb composed of multiple modules.  
- Creation and management of the **manual** to guide the expert.  
- User interface for navigating the game.  
- **Translation system** with support for French and English.  

### Current Status and Challenges  
Development has reached a first playable version with the basics of gameplay. However, a testing phase with multiple players is necessary to fix bugs and adjust mechanics. Finding new module ideas remains a creative challenge.  

### What I Learned  
- Deepening my skills in **Unity** and **C#**.  
- Managing **asymmetric cooperation** in a multiplayer game.  
- Implementing a **multilingual system** integrated into gameplay.  

### Project Evolution  
Development is currently on pause to allow for testing and debugging. Eventually, my goal is to continue improving it until achieving a stable and complete version, potentially published on **itch.io**.
