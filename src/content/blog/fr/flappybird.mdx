# Flappy Bird

**Flappy Bird** est un projet réalisé dans le cadre d’un cours de multimédia durant mon **BUT**. Le but était de créer un clone en 2D du célèbre jeu mobile pour découvrir les bases du moteur **Unity**.  

## Détails du projet

### Contexte  

Ce projet faisait partie d’un apprentissage guidé sur Unity. Bien que j’étais déjà familier avec l’outil, il m’a permis de renforcer mes bases et d’aller plus loin dans l’expérimentation.  

### Fonctionnalités principales  
- Recréation du gameplay classique de **Flappy Bird**.  
- Ajout d’**animations** pour améliorer la fluidité.  
- Mise en place d’un **effet de parallaxe** pour enrichir le rendu visuel.  

### Ce que j’ai appris  
- Approfondissement de mes connaissances en **Unity 2D**.  
- Gestion des **animations et effets visuels** dans un jeu simple.  
- Utilisation des **scripts C#** pour la mécanique de gameplay.
