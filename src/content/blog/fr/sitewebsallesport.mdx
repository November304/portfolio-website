# Site Web pour salle de sport

Ce projet consiste à développer un **site web pour une salle de sport**, avec un backend en **PHP/Symfony**, une base de données **MariaDB**, une **API REST** sécurisée, et un frontend en **Angular**.  

## Détails du projet

### Contexte  

Le projet a été réalisé en **équipe** dans le cadre de mon BUT. L’objectif était de créer un site complet permettant aux responsables de la salle de suivre les données des adhérents et de visualiser des statistiques.  

### Fonctionnalités principales  
- Création d’une **API REST sécurisée** pour le backend.  
- Gestion des **données utilisateurs et des statistiques** pour les responsables.  
- Intégration d’un **frontend Angular** pour afficher les informations et statistiques de manière dynamique.  

### Ce que j’ai appris  
- Développement d’un **backend complet avec Symfony et PHP**.  
- Sécurisation et gestion d’une **API REST**.  
- Manipulation et structuration de **bases de données MariaDB**.  
- Collaboration en équipe pour un projet web complet.
